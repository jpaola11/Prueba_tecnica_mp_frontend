# MP Pao Frontend

Frontend React + TypeScript (Vite) con estética institucional, grid layout y capa de servicios con interceptores.

## Scripts

- `npm install`
- `npm run dev` – desarrollo
- `npm run build` – build producción
- `npm run preview` – preview

Configura `VITE_API_BASE_URL` en un archivo `.env` para apuntar al backend.
